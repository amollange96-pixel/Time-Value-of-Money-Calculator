Financial Formulas Reference & Variable Definitions

Understand the core principles governing the Time Value of Money (TVM).

1. Future Value (FV)

FV = PV × (1 + r)ⁿ

Evaluates how much money an investment made today will grow into over n periods at an interest rate of r per period.

  • FV: Future Value (accumulated future balance)
  • PV: Present Value (initial capital or deposit today)
  • r: Interest rate per compounding period in decimal (e.g. 8% = 0.08)
  • n: Number of compounding periods

2. Present Value (PV)

PV = FV / (1 + r)ⁿ

Calculates the current dollar value of a designated cash sum expected to be received in the future, discounted at rate r.

  • PV: Present Value (discounted current equivalent)
  • FV: Future Value (nominal target sum to receive)
  • r: Discount rate per period
  • n: Number of discounting periods

3. Future Value of Annuity

FV = PMT × [((1 + r)ⁿ - 1) / r]

Determines the final total value of a steady stream of equal periodic deposits made at the end of each period.

  • PMT: Periodic payment or contribution
  • r: Periodic interest rate
  • n: Number of regular payments
  • Note: If r = 0, formula simplifies to: FV = PMT × n

4. Present Value of Annuity

PV = PMT × [1 - (1 + r)⁻ⁿ] / r

Computes the single upfront lump sum required today that would duplicate receiving a stream of periodic payments over n intervals.

  • PMT: Periodic payment amount
  • r: Periodic discount rate
  • n: Total number of installments
  • Note: If r = 0, formula simplifies to: PV = PMT × n

5. Loan Payment (Amortization)

PMT = PV × [r / (1 - (1 + r)⁻ⁿ)]

Determines the fixed periodic installment (EMI) required to completely retire a debt over n periods.

  • PV: Loan Amount (Principal borrowed)
  • r: Periodic interest rate: (Annual Rate / Frequency / 100)
  • n: Total number of payments: (Years × Frequency)
  • PMT: Periodic installment amount

6. Compound Interest

A = P × (1 + r/m)^(m × t)

Calculates compound interest accrued when interest is calculated and reinvested m times per calendar year.

  • A: Final accrued total balance
  • P: Initial Principal amount
  • r: Annual nominal interest rate in decimal form
  • m: Compounding frequency per year (1=Annual, 12=Monthly, 365=Daily)
  • t: Total time duration in years
